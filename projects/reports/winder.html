A filament winder I built to go with a Filabot EX2 extruder. It makes recycled filament come out a steady width. I designed the whole thing, from the frame to the motor control, and wrote the code that runs it. I put it on Printables, where it's been downloaded over 150 times.

1How it works

A magnet and a hall-effect sensor measure the width of the filament. It runs between them and pushes the sensor away from the magnet, and the hall sensor reads how far. An Arduino watches that number and speeds the winder up or slows it down to keep the width steady.

The thicker the filament, the further it pushes the sensor and the lower the number goes. It reads 760 with nothing in it and 600 with 1.75 mm filament in it. Those two numbers are in the code.

const int baseReading = 760;       // empty
const int filamentDiameter = 600;  // 1.75mm

2The code

The whole sketch is about 60 lines of Arduino C++. It reads the sensor 10 times a second. If the filament is too thin it slows the motor down a notch, so the filament gets thicker. If it's too thick it speeds the motor up a notch, so it gets thinner.

if (sensorValue >= filamentDiameter + 10) {
  motorSpeed = motorSpeed - 5;   // too thin
} else if (sensorValue <= filamentDiameter - 10) {
  motorSpeed = motorSpeed + 5;   // too thick
}
analogWrite(pwmPinMotor, motorSpeed);

There's a dead band of 10 either side of the target so it doesn't hunt back and forth over noise. The speed is kept between 100 and 200 out of 255. If nothing is in the sensor, the motor stops. A fan runs flat out the whole time.

It holds the width to around ±0.05 mm.
