I built this for a Filabot EX2 plastic extruder. The extruder makes filament out of recycled plastic, but the diameter is sensitive to how fast the take-up spool pulls it. I wanted the winder to correct that on its own rather than needing someone to adjust it constantly. I designed the printed frame, sensor, motor drive, and Arduino code. I've since put the files on Printables; they've been downloaded more than 150 times.

1Control

The filament runs through a little mechanical gauge between a magnet and a Hall-effect sensor. A thicker strand moves the sensor farther from the magnet, changing the analog reading. I use that as a rough diameter measurement. The Arduino changes the winding speed in response: pull faster to stretch the still-soft filament thinner, or slow down to let it stay thicker.

The reading is about 760 with no filament and about 600 with 1.75 mm filament. I calibrated those two positions and use them as reference values in the code. It's a fairly crude gauge, but I didn't need an expensive optical diameter sensor to try closed-loop control.

const int baseReading = 760;       // empty
const int filamentDiameter = 600;  // 1.75mm

2Firmware

The sketch is roughly 60 lines of Arduino C++. It samples the Hall sensor 10 times a second and nudges the motor PWM up or down depending on the error. Thin filament means less pull; thick filament means more. I kept the controller deliberately simple because the process responds slowly and the sensor isn't particularly clean.

if (sensorValue >= filamentDiameter + 10) {
  motorSpeed = motorSpeed - 5;   // too thin
} else if (sensorValue <= filamentDiameter - 10) {
  motorSpeed = motorSpeed + 5;   // too thick
}
analogWrite(pwmPinMotor, motorSpeed);

There's a deadband of 10 sensor counts either side of the setpoint so the motor doesn't keep correcting noise. PWM is clamped between 100 and 200 out of 255. With no filament detected, the winder stops. The fan runs continuously.

In my tests I got the diameter to stay around ±0.05 mm.
